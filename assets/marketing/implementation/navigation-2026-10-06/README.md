本轮在 codex/homepage-figma 中继续实现审阅意见，仅交付本地版本。

## 导航约定

| 入口 | 统一目标 | 用途 |
| --- | --- | --- |
| 顶部快速开始 | /guide/ | Agent 安装、配对、验证、运行任务 |
| 顶部使用文档 | /docs/ | 按用户任务组织的文档索引 |
| 顶部下载 App | /download | 桌面扫码、手机直接打开 App Store |
| 首页连接我的电脑 | #agent-install | 当前页复制安装提示词 |
| 明确标注 App Store 下载 | App Store | 直接下载 |
| English | 当前文章的英文对应页 | 保留文档上下文 |

中文页共享导航和侧栏。首页主视觉保持既有方案；下载为导航唯一主按钮。手机保留下载入口，其余入口进入菜单；文档搜索在菜单中显示完整按钮。安装、配对提示词在首页、快速开始和配对指南间复用同一组件与文本，原 PATH 修复要求保留。快速开始的下一页为运行任务。

## 验证

- npm run check：TypeScript、生产构建、语言对应检查、静态内容与内部链接检查通过，见 check.log。
- git diff --check 通过；英文文档无差异。
- 中文 MDX 的下载/配对页与英文 Markdown 扩展名不同，配置仅排除这两个路由的文件名比较；check-site 显式验证两个语言的输出路由存在。
- 首页实测 CSS 视口 1280×720、1440×900、768×1024、390×844、320×740 均无横向溢出。截图对应 home-{width}.jpg。浏览器原有 120% 缩放保留，通过调整视口覆盖值获得目标 CSS 宽度；图像像素宽度相应为 1.2 倍。
- 文档共享目录、搜索结果跳转、移动端侧栏、菜单路由关闭、语言对应文章和下一页入口均经过浏览器操作验证。
- 语言菜单 Escape/外部点击关闭；手机菜单 Escape 返回触发按钮；搜索 Escape 返回可见搜索按钮。
- 安装902字符、配对801字符：实际 Clipboard 写入成功且逐字匹配对应提示词。没有读取用户原有剪贴板。两种反馈独立。
- 模拟复制拒绝及后备复制失败后，只展开对应的配对文本并显示可访问错误反馈；刷新已清除故障注入。安装失败分支沿用上一轮共享组件验收。
- 下载后配对锚点位于固定导航下方；下载二维码用 Apple Vision 解码，准确指向 RunBuoy App Store 页面。来源见 qr-provenance.json。
- 浏览器检查数据见 interaction-checks.json；文档及手机菜单截图见 02–05 文件。
