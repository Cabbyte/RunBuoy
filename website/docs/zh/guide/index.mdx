# 快速开始

下载 App，交给 Agent，扫码配对。任务留在电脑，进展带到手边。

先在 iPhone [下载 RunBuoy](/download)（iOS 18+），准备一台 Mac 或 Linux 电脑，以及支持 Skill 的 Agent。

<div id="agent-install" />

## 使用 Agent 安装（推荐）

复制提示词，交给 Agent 完成 Skill、CLI 与 PATH 验证。已经安装时会先检查现有环境；此步骤不会配对或启动任务。

<GuidePrompt kind="install" />

## 配对 iPhone

安装验证通过后，把配对提示词交给同一个 Agent。它会检查已有配对或待完成会话，再展示二维码或短期配对码。

<GuidePrompt kind="pair" />

在 iPhone 打开 **RunBuoy → 设置 → 配对新电脑**，扫码并确认电脑身份，再告诉 Agent 已完成扫码。Agent 会恢复会话并检查连接；已经配对时保留现有连接。[无法扫码或连接异常？](/guide/pairing)

## 验证第一条动态

配对成功后，主动在电脑运行一次演示，或明确让 Agent 执行：

```bash
runbuoy demo live-activity
```

确认 iPhone 收到演示状态后，继续[运行自己的任务](/guide/run)。安装和配对提示词都不会自动启动演示或任务。

普通命令可以报告运行状态与结果；百分比、阶段和预计完成时间需要任务显式报告，详见[进度模式](/guide/progress)。

## 手动安装与进阶说明

不使用 Agent，或需要检查依赖时，再展开以下说明。

<details id="manual-install">
<summary>手动安装 CLI 与可选 Python API</summary>

**手动安装 CLI**

:::tip 手动安装 · 当前可用
下面的 uv 流程是公开、可执行的安装方式，支持 macOS 与 Linux。
:::

**1. 安装系统依赖与 uv**

<Tabs>
<Tab label="macOS">

```bash
brew install tmux uv
uv tool update-shell
```

</Tab>
<Tab label="Debian / Ubuntu">

```bash
sudo apt update
sudo apt install tmux
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool update-shell
```

</Tab>
<Tab label="Fedora">

```bash
sudo dnf install tmux
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool update-shell
```

</Tab>
<Tab label="Arch Linux">

```bash
sudo pacman -S tmux
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool update-shell
```

</Tab>
</Tabs>

重启终端后继续。uv 会自动下载并管理所需的 Python 3.12；`tmux` 是必须通过系统包管理器安装的依赖。

**2. 安装 CLI**

```bash
uv tool install --python 3.12 runbuoy
uv tool update-shell
export PATH="$(uv tool dir --bin):$PATH"
hash -r
command -v runbuoy
```

以上 PATH 命令适用于 Bash / Zsh；Fish 使用 `fish_add_path (uv tool dir --bin)`。安装后在新终端再次运行 `command -v runbuoy` 和 `runbuoy --version`，确认配置已保存。若仍找不到命令，请查看[PATH 排查](/guide/install#troubleshooting)。

根据实际使用的 Shell 选择一个补全命令：

<Tabs>
<Tab label="Bash">

```bash
runbuoy completion install bash
```

</Tab>
<Tab label="Zsh">

```bash
runbuoy completion install zsh
```

</Tab>
<Tab label="Fish">

```bash
runbuoy completion install fish
```

</Tab>
</Tabs>

**3. 验证安装**

```bash
runbuoy --version
runbuoy doctor --json
runbuoy capabilities --json
```

doctor schema v2 的 `local_ready=true` 表示平台、Python、tmux 与本地存储已满足执行条件。`delivery.ready` 是独立状态；尚未配对或 Server 不可达时，本地 Run 仍完整可用。

**可选：在 Python 项目中使用 API**

`uv tool` 创建的 CLI 环境与项目 Python 环境相互隔离。如果代码需要 `from runbuoy import progress` 等 API，请在项目根目录另行声明依赖：

```bash
cd my-project
uv add --optional runbuoy runbuoy
uv sync --extra runbuoy
```

这是正常的双环境安装，不是重复配置。SDK 调用必须发生在 RunBuoy 启动的目标进程树内；详见[进度模式](/guide/progress)。

**已经手动安装了 CLI？**

仍然可以在任何时候使用上面的 Agent 提示词补装 Skill。Agent 会先运行 `command -v runbuoy`，检测到现有 CLI 后不会重复安装，只会继续验证环境。
